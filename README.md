# MAKEBREW

A minimal, Zsh-based runtime for personal computers.

MAKEBREW is designed to open files, execute programs,
and build software using the capabilities of its host.

## Philosophy

One runtime.
Any file.
No unnecessary dependencies.

## Architecture

- open: delegate files to the operating system
- run: execute programs using available runtimes
- make: build source code using available toolchains

## Gauntlet

Gauntlet is an example of a character-based interface
that can be developed alongside MAKEBREW.

## Platform

macOS with Zsh.

## Status

Experimental.
